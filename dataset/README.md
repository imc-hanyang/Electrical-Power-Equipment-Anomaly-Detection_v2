# dataset/ — 추론 입력 폴더

여기에 검사할 전선 crop 이미지를 넣으세요.

```
dataset/
├── Anomaly/   # 이상 이미지 (라벨 있을 때만; 성능 자동계산)
└── Normal/    # 정상 이미지
```

- **라벨 없이 판정만** 하려면: 이미지를 아무 하위폴더에나 넣거나 `Normal/`·`Anomaly/`에 섞어 넣고 실행 → predictions.csv 로 판정 결과.
- **성능(P/R/F1/AUROC)까지** 보려면: 정답 기준으로 `Anomaly/`·`Normal/`에 나눠 넣으면 자동 계산.
- 이미지는 **결함 영역 crop** 이어야 정확합니다 (전체 사진 X).

※ 이미지 파일은 git에 커밋되지 않습니다(.gitignore). 폴더 구조만 유지됩니다.
